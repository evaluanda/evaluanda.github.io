Conectar EvaluAnda con una IA

Planifica conversando: pídele a tu IA que revise una unidad, que proponga sesiones, que mueva tus tareas al lunes… y ella lee y escribe en tu cuaderno. Vale con Claude, Codex o cualquier IA compatible con MCP (el estándar para conectar herramientas a una IA).

Cada profe monta la suya. La conexión es personal: tu IA solo ve tu planificación y tus tareas. Nunca ve a tu alumnado ni sus notas: no existe ninguna herramienta que los exponga. Y no puede borrar: crea y edita; borrar se hace desde la app.

Cómo funciona

Tu IA (en tu ordenador)
   │  MCP por stdio — nada publicado en internet
   ▼
servidor Node (en tu ordenador)
   │  HTTPS + token secreto
   ▼
Apps Script «EvaluAnda — API» (se ejecuta como TÚ)
   ▼
tu cuaderno, en tu Drive

Necesitas

  • Un ordenador con Node 20 o superior (compruébalo con node --version).
  • Una IA de escritorio que admita MCP: Claude Desktop (plan de pago), Codex, etc.
  • Haber entrado alguna vez en EvaluAnda (para que exista tu cuaderno).

1 Copia tus dos datos desde EvaluAnda

En la app: Ajustes › Conector de IA (MCP).

  • Copiar id del cuaderno → lo usarás como CUADERNO_ID.
  • Copiar clave de cifrado → lo usarás como CIF_KEY. Es lo que permite a la IA leer y escribir el texto de tus tareas (va cifrado porque puede nombrar alumnado). Es privada: pégala solo en tu propio proyecto. Si no quieres que la IA toque el texto de tus tareas, no la pongas (seguirá viendo fechas, clases y estado).

2 Crea tu API en Apps Script (10 min)

  1. Entra en script.google.com con tu cuenta de g.educaand.es → Nuevo proyecto. Llámalo «EvaluAnda — API».
  2. Pega el código de Api.gs (sustituye todo lo que haya).
  3. Inventa un token: una cadena larga y aleatoria (32 caracteres o más). Guárdala.
  4. ⚙ Configuración del proyecto › Propiedades de la secuencia de comandos → añade:
    PropiedadValor
    API_TOKENel token que te has inventado
    CUADERNO_IDel id copiado en el paso 1
    CIF_KEY(opcional) la clave copiada en el paso 1
  5. Implementar › Nueva implementación › Aplicación web, con Ejecutar como: Yo y Quién tiene acceso: Cualquier usuario. Autoriza y copia la URL que acaba en /exec.

«Cualquier usuario» suena abierto, pero sin tu token no se puede hacer nada. Comprobación: abre esa URL en el navegador; debe decir «El despliegue funciona».

3 Instala el servidor en tu ordenador (5 min)

  1. Descarga la carpeta servidor (por ejemplo en ~/evaluanda-mcp).
  2. En una terminal, dentro de esa carpeta: npm install
  3. Para probarlo, copia config.ejemplo.json a config.json, pon tu URL y tu token, y ejecuta npm run comprobar. Debe salir «✓ Conexión correcta».

4 Conéctalo a tu IA (3 min)

En todos los casos la ruta a index.js debe ser absoluta. Después, reinicia la aplicación de la IA.

Claude Desktop

Edita claude_desktop_config.json (Mac: ~/Library/Application Support/Claude/; Windows: %APPDATA%\Claude\):

{
  "mcpServers": {
    "evaluanda": {
      "command": "node",
      "args": ["/Users/TU-USUARIO/evaluanda-mcp/index.js"],
      "env": {
        "EVALUANDA_URL": "https://script.google.com/macros/s/…/exec",
        "EVALUANDA_TOKEN": "tu-token"
      }
    }
  }
}

Codex

Añade a ~/.codex/config.toml:

[mcp_servers.evaluanda]
command = "node"
args = ["/Users/TU-USUARIO/evaluanda-mcp/index.js"]
env = { EVALUANDA_URL = "https://script.google.com/macros/s/…/exec", EVALUANDA_TOKEN = "tu-token" }

Otra IA

Cualquier cliente MCP que lance servidores por stdio vale: el comando es node /ruta/a/index.js con las variables EVALUANDA_URL y EVALUANDA_TOKEN.

Primera prueba: «comprueba la conexión con EvaluAnda». Debe responder con el nombre de tu cuaderno.

5 Qué le puedes pedir

  • Sesiones: «Mira mi unidad de ecosistemas de 5º. ¿Está muy cargada?» · «Añade una sesión de repaso antes del examen con los criterios que ya trabaja la unidad».
  • Tareas: «Apúntame corregir los exámenes de 5ºA para el viernes, en esa clase» · «Pasa al lunes las tareas pendientes de esta semana» · «Liga la tarea del orden del día a la reunión de ciclo del jueves».

Consejo: pídele que te enseñe lo que va a hacer antes de hacerlo; escribe en tu cuaderno de verdad. Las descripciones admiten formato (negrita, listas, enlaces).

6 Dudas frecuentes

¿Puede ver a mi alumnado o mis notas?

No. Ni el servidor ni la API tienen ninguna forma de leerlos.

¿Y si alguien consigue mi token?

Podría leer y editar tu planificación (y el texto de tus tareas si pusiste CIF_KEY). Guárdalo como una contraseña. Si se filtra, cambia API_TOKEN en las propiedades del script y en la configuración de tu IA.

Hay una versión nueva: ¿cómo actualizo?

Vuelve a pegar Api.gs y publícalo en la misma implementación (Implementar › Gestionar implementaciones › ✏️ › Versión: nueva; así la URL no cambia), y sustituye index.js. Reinicia la IA.

Algo no funciona

«La API no devolvió JSON»: la URL no acaba en /exec o el despliegue no es «Yo / Cualquier usuario». «Token incorrecto»: no coincide con API_TOKEN. La IA no ve las herramientas: la ruta no es absoluta o falta reiniciarla. npm run comprobar te dice si el fallo está antes o después del servidor.
